# NCTGIS Frontend

React application for interactive visualization of desertification monitoring in Toshka.

## Structure
- `src/components/`: Reusable UI elements (Map views, NDVI legends, metric cards, charts).
- `src/pages/`: Main application views (Dashboard, Time-series analysis, Zone explorer).
- `src/services/`: API connectors to the Django GeoDjango REST backend and Neon cloud endpoints.
